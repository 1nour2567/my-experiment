# Self Core Experiments

From v4 to GCG dual-rule: a complete experimental pipeline testing whether machines can know what they don't know — without external labels.

## Structure
- self-core-experiment.py → v4 (baseline)
- self-core-experiment-v5.py → v5 (structure features)
- v5_highres.py → v5 high-resolution λ sweep
- mvp-experiment-v1.py → MVP (structure verifier, paused)
- gcg-dual-rule-experiment.py → GCG dual-rule (Hebbian + Verifier)
- *.md → design documents

## Results
- self_core_v4_results.json → v4 data (ECE vs λ, 3 groups)
